# Glint Smart Tracker

Glint.org is a mobile app designed for individuals who want to track their daily calorie intake effortlessly using AI. The core functionality includes:

AI-Powered Food Calorie Analysis

Users can take a photo of their meal or manually enter food details.

The AI instantly estimates calorie count, macronutrient breakdown (carbs, protein, fat), and portion size accuracy.

For packaged foods, it can scan barcodes or read nutrition labels via OCR.
